Runtime Analysis Sequence (online path)

One request, gated tool/retrieval steps, evidence before generation, verification after. Disabled controls are marked disabled — never faked.

The invariant order

  • Evidence is built (steps 7–9) before the memo (10). Generation never precedes retrieval.
  • Verification (12–13) is downstream of generation — it can only check what was produced.
  • The memo cites only IDs present in the EvidencePackets from step 8.

The control gate (opt frame)

  • Steps 5–8 run only when include_news_sentiment / include_filing_analysis are true.
  • Disabled → response marks that source disabled. No fabricated sentiment, no phantom SEC citation.
  • max_news_articles bounds step 5. These are the test-plan §4 control cases.

Failure paths (not drawn, but specified)

  • Retrieval returns nothing → memo states the limitation; verifier flags low support.
  • Tool/LLM failure → run status failed/degraded with a safe error; step 14 still persists it.
  • Async: client polls GET /runs/{id} until terminal — step 15 is the poll resolution.
